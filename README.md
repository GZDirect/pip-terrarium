# Pip terráriuma

Ugrópókos, tamagocsi-szerű 3D játék. Pip, a fehér bundájú ugrópók egy vintage konyha pultján álló terráriumban él: vadászik, iszik a permetcseppekből, ugrál a levelek között, és este a kókuszkuckójában alszik. A napszak a játékos saját helyi idejét követi. Magyarul és angolul is játszható (a böngésző nyelve alapján vált).

*Pip's Terrarium – a cosy 3D jumping-spider care game. Available in English and Hungarian.*

**Játék:** https://gzdirect.github.io/pip-terrarium/
