# Pip terráriuma

Ugrópókos, tamagocsi-szerű 3D játék. Pip, a fehér bundájú ugrópók egy vintage konyha pultján álló terráriumban él: vadászik, iszik a permetcseppekből, ugrál a levelek között, és este a kókuszkuckójában alszik. A napszak a valódi budapesti időt követi.

**Játék:** https://gzdirect.github.io/pip-terrarium/
